# 草稿归档与批量导出（合成需求，用于校验设计方法选型）

## 背景

草稿列表支持协作编辑。需求增加两件事：成员可以归档已提交的草稿；用户可以批量导出草稿。

## 功能规则

- 草稿名称长度 1–20。
- 草稿状态有草稿、已提交、已归档；提交后可以归档。
- 团队所有者可以批量导出全团队草稿；普通成员只能导出自己创建的草稿。
- 单次导出最多 50 条草稿。
- 导出是异步任务：提交后返回受理结果，稍后可查看导出文件。

## 原型备注

原型里导出入口只出现在"全部草稿"页签下，没有说明成员从"我的草稿"导出时的行为。原型也没有画出归档后的入口。

## 其它

- 本轮不覆盖草稿内容编辑，也不覆盖导出文件的内容格式校验。
