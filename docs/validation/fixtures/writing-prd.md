# 团队邀请（合成需求，用于校验澄清闸门）

## 背景

团队所有者可以把外部联系人邀请进团队。联系人通过邀请链接接受后即成为团队成员。

## 功能规则

- 团队所有者可以向邮箱地址发送邀请。
- 邀请发送后会在团队列表里留下一条邀请记录，状态为"待接受"。
- 邀请链接 3 天内有效，过期后访问会提示链接已失效。
- 联系人接受邀请后进入团队，出现在成员列表中。
- 同一个邮箱在同一团队内重复收到邀请时，只保留一条有效邀请记录。

## 原型备注

原型标注的是"链接 7 天内有效"，与上面的 3 天不一致。原型没有说明从哪个时刻开始计算有效期，也没有说明接受邀请后新成员在团队里的角色。

## 其它

- 邀请功能不在批量邀请的范围内，本轮不覆盖。
- 邮件由其它系统发送，本需求只覆盖"创建邀请记录"到"接受后成为成员"这一段。
