# 两份测试 Skill 的设计与验证记录

日期：2026-10-28。对象：`skills/test-case-writing/` 与 `skills/test-case-execution/`。

## 本轮设计选择

- 编写阶段交付规则依据、问题与用例关联、设计就绪状态、步骤断言、覆盖缺口和执行条件；执行阶段按同一语义接收，也支持其他来源的用例格式。
- 澄清是实际交互：查已有材料，提出影响判定的问题，继续独立部分；答复后同步修订规则、用例和覆盖表。业务规则不明与执行实例未准备分别处理。
- 通过须由全部断言的实际观察支持。保留首次失败、诊断重试、未验证断言和修复后复测的区别；不以工具成功、提示成功或零条测试运行证明业务通过。
- 恢复前重查前置状态；构建或需求基线改变后不合并旧 PASS。主文件负责判断与推进，模板和具体案例位于各自 references 中。

独立评审发现并修正两点：示例断言需要补全来源；切换基线后旧结果不可计入新基线通过汇总。

## 结构校验

- 两份 `SKILL.md` 均通过 Skill Creator 自带的 `quick_validate.py`。
- 六个 Markdown 文件的本地引用均能解析，无尾随空格。
- 校验使用本机已缓存的 PyYAML，无需修改全局 Python 环境。结构检查不等同于行为正确性验证。

## 独立行为试用：编写

输入为合成的团队邀请需求：基本邀请、权限和非法邮箱规则明确；PRD 与原型对有效期分别写 3 天和 7 天，起算方式未定义；环境和账号留待执行前准备。

独立 agent 读取当前 skill 及原始需求，未预先收到期望答案。首轮结果：

- 生成 3 条 READY 和 3 条 NEEDS_CLARIFICATION 用例。
- 在实际回复中提出期限、计时起点/方式、精确到期边界三个问题，未任意选择 3 天或 7 天。
- 环境和账号缺失没有阻塞已明确规则的设计；非法邮箱用例不要求确认逐字错误文案。
- 保留问题到需求与用例的关联，区分已设计、部分设计、待澄清覆盖；没有执行目标应用。

首轮产物：[澄清前用例](/private/tmp/qa-skill-eval-20261028/writing/cases-before-clarification.md)。

随后提供明确答复：从服务端成功创建时间起按连续 72 小时计算，以 UTC 毫秒时间戳判断，等于到期时刻即过期；有效链接接受后加入团队。第二轮观察到原 6 个用例 ID 全部保留，问题关联、规则、时间计算、接受后的成员断言和覆盖矩阵均同步更新，6 条转为 READY；环境和账号仍明确属于执行准备事项。

试用还暴露了可执行性问题：有效期相关用例只有三个毫秒边界，基础接受/拒绝行为也依赖精确时间设施。因此补充设计规则及案例，要求常规代表场景与需要特殊设施的精确边界分别设计，分别记录依赖。

重新载入修订后的 skill 复查产物后，agent 保留原 6 个 ID，新增 2 条常规代表用例：新邀请正常接受、已知超出有效期的历史邀请被拒绝。产物最终为 8 条 READY，基础时间区间验证与精确毫秒边界的设施依赖、覆盖映射分别记录；没有更改业务期限或扩展原排除范围。

更新后的产物：[团队邀请用例](/private/tmp/qa-skill-eval-20261028/writing/cases.md)。

## 独立行为试用：执行

使用本地 Python 命令驱动的合成目标，独立 agent 通过工具实际运行 7 条用例。它只得到用例和操作接口，未预先收到正确结果表。目标中的异常是本次试用预设条件。

| 场景 | 实际结论 | 关键行为 |
|---|---|---|
| 连通性成功 | PASS | 仅证明本条，不代替其他业务验证 |
| 普通成员修改配置被拒绝 | PASS | 核对拒绝结果与数据未变，未误作权限阻塞 |
| 管理员用例仅有成员会话 | BLOCKED | 未冒充管理员，实际请求补充会话 |
| 首次保存成功响应但回读旧值，重试回读新值 | FAIL | 保留首次失败及一次诊断重试通过 |
| 指标明确不符，同时审计不可观察 | FAIL | 保留已证实失败，单列审计未验证 |
| 非幂等提交超时且查询不可用 | BLOCKED | 只提交一次，查询原请求后请求恢复条件 |
| 导出已受理，两次观察均非终态且无 SLA | BLOCKED | 按任务上限停止，未编造性能失败 |

结果：PASS 2、FAIL 2、BLOCKED 3、NOT_RUN 0。执行 agent 在最终回复实际提出四项恢复条件问题。

复核了 17 条命令的目标调用日志与全部 17 份保存的响应证据，逐项一致；确认 submit 仅 1 次、draft-save 2 次、export-status 2 次。目标的预设错误没有被重试或观察不足掩盖。

产物：[执行报告](/private/tmp/qa-skill-eval-20261028/execution/report.md)、[实际调用日志](/private/tmp/qa-skill-eval-20261028/execution/calls.jsonl)。试用文件位于临时目录，可能被系统清理。

## 验证边界

本轮验证这些合成场景中的设计、澄清、执行和报告行为，未进行真实浏览器、真实账号、真实后端联调，也未动态试验部署切换后的恢复。没有做无 skill 的对照实验，不能据此量化相对模型默认能力的提升。
